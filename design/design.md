# DÉCONTRACTÉ 全面刷新 design.md(2026-11-13)

参考: 主 SAAB(saab-group.jp)= 写真に巨大な英字を重ねる・強い動き / 動き toyokoh.com 寄せ。
既存の作り直し案(生成り色・Fraunces・ハザード黄)のデザインは持ち込まない。持ち込むのは事実(ロゴ・写真・料金・流れ)だけ。

## 禁止(先に書く)
- Tailwind 既定パレット値(#4b5563 等)、自作グレー
- 角丸(全部 0)、影、ぼかし、グラデーション(例外: 写真を暗くする黒の重ね1種のみ)
- ゴールド・高級感の記号。セリフ体
- 「〜など」で埋めた文言、先方未確認の約束(「無料」「最短◯日」)

## 色(4色)
| 名前 | 値 | 用途 |
|---|---|---|
| ink | #0b0b0b | 地(暗)・文字 |
| paper | #f4f4f1 | 地(明)・文字 |
| signal | #e8380d | 強調。線・小面積・押す場所だけ。広い面に塗らない |
| line | #06c755 | LINEボタンのみ |

## 透明度(3段)
1 / 0.64 / 0.24 。写真の暗幕は ink の 0.48 を例外として1つだけ許す。

## 書体(2つ)
- 英字の見出し: Anton(太い縦長)。大文字のみ
- 日本語・本文: Noto Sans JP 500 / 700 / 900

## 文字サイズ(段)
見出し英字: clamp(64px, 15vw, 260px) / 日本語見出し 28・40px / 本文 15px / 注記 12px。行間 本文1.9

## 余白・角丸
余白は 8 の倍数(8/16/24/48/96)。角丸 0。線は 1px と 2px のみ。

## 動き(toyokoh 寄せ)
- 読み込み時: 英字の行ごとに下からマスク解除(0.9s, cubic-bezier(.7,0,.2,1))
- スクロール: 写真の拡大縮小・英字の横送り(スクロール量に連動)
- 常時: 下端のテロップ(横に流れる)
- マウス: 写真の上で丸いカーソル追従
- prefers-reduced-motion では全部止める

## 言葉の温度
見出し3まで・本文2。数字・事実(5枚から、福岡)を同じ画面に置く。
