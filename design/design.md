# DÉCONTRACTÉ 全面刷新 design.md — D案(2026-11-14)

A案(黒地・写真に巨大英字)は「全体的なトンマナが違う」で不採用(2026-11-13 河添)。
参考14本(ezobolic / REVEL / STYLEM / belmo / AFURI BREWING / 古川製作所 / 北海道イエロースターズ / ナミナミ / SERIOUS CERAMIC / TATORU / ニシザキ工芸 / DOD / 四国洗機 / サンフロロ)から、
**配置・色の使い方・動きの作り**だけを取り入れる。各サイトの写真・文章・ロゴ・コードは使わない。

## 14本の共通項(実測: 色・書体・使用ライブラリ)
- 地は明るいグレー〜オフホワイト(#f5f5f5 / #fafafa / #f4f5f6)、文字はほぼ黒(#121212 / #1d1d1d)
- 差し色は赤1色(#c83531 / #c8372f / #fe3620)
- 英字はグロテスク体を太く、ブランド名や見出しを画面端で切るほど大きく(ezobolic / DOD)
- 日本語の見出しは極太で大きく、何のサイトかを最初の1行で言う(TATORU / belmo)
- 動きは Lenis(慣性スクロール)＋ GSAP ScrollTrigger が14本中6本

## 禁止
- Tailwind 既定パレット値、自作グレー、影、ぼかし、グラデーション
- 角丸(全部 0)、ゴールド・高級感の記号、セリフ体
- 「〜など」で埋めた文言、先方未確認の約束(「無料」「最短◯日」)

## 色(5色)
| 名前 | 値 | 用途 |
|---|---|---|
| ink | #121212 | 文字・暗い面(フッター) |
| paper | #f2f2f0 | 地(明るいグレー) |
| white | #ffffff | 交互の帯・商品画像の地 |
| signal | #c8372f | 強調・ボタン・番号。白文字を載せる |
| line | #06c755 | LINEボタンのみ(文字は ink) |

## 透明度(3段)
1 / 0.64 / 0.24

## 書体(2つ)
- 英字: DM Sans 700(大文字・字間 -0.04em)。社名の巨大表示は -0.06em
- 日本語・本文: Noto Sans JP 500 / 700 / 900

## 文字サイズ
トップ日本語見出し clamp(32px, 5.4vw, 80px) 900 / 英字見出し clamp(48px, 8vw, 128px) / 本文 15px / 注記 12px

## 余白・角丸
余白は 8 の倍数。角丸 0。線は 1px と 2px。

## 動き
- 読み込み: 日本語見出しを行ごとに下からマスク解除
- スクロール: Lenis の慣性スクロール、写真の拡大、巨大な社名・英字の横送り(スクロール量に連動)
- 常時: 下端のテロップ
- マウス: 写真の上で四角いカーソル追従
- prefers-reduced-motion では全部止める(Lenis も使わない)

## 言葉の温度
見出し3まで・本文2。数字・事実(5枚から、福岡)を同じ画面に置く。
